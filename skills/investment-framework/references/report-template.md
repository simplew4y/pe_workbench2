# 投资框架报告模板（七节）

报告是 `analysis-state.json` 的视图。每节引用状态里的 ID，读者可以顺着 ID 回到证据；不要让报告和状态各说一套。

## 写作前先记住三条

1. **目标价是模型输出，倍数是输入。** `10x → 11x` 不等于“目标价 +10%”；还要看 ARR/EPS 基数、汇率、股数、净现金。倍数必须写清口径与期间，如 `11x 2026E ARR`，不能简称“PE”。
2. **不同方法不能写成连续目标价。** DCF 的 1560 和 ARR 倍数法的 320/458 是两种模型；要并列、标“不可比”、给 bridge，不能写 `1560 → 320 → 458`。
3. **归因只列进入公式的驱动。** 不在某个 `V.drivers` 里的假设（例如 ARR 倍数法里的 A3 利润率）可以解释观点，不能解释目标价变化。

## 写作规则

- 结论先行：第二节先给判断，再给依据。
- 七节主体保留，可选空行、小节和空表省略；不输出“暂无”“counter_ids 为空”“见校验说明”等占位文字。有效证据引用和研究 ID 仍保留，不能为填空编造反证。
- 回答、执行摘要与正文均不输出校验统计、原因码、结构验收、草稿升级流程或泛化免责；不添加“诚实记录、非遗漏、非逻辑错误”等自我辩护。
- 同一限制只在最相关的位置说明一次。仅将影响结论、估值计算或监测执行的缺口写成具体事实，不因存在 warning 自动新增复核项；核心模型价、现价、空间缺失仍明确标注。
- 正文写业务名称、年份和自然语言路径，不写裸单元格坐标；坐标放证据定位。
- 数字带单位、期间、口径；未知写“未确定”，不写 0。
- 图表只在有真实数据时生成；没有就写缺口，不画假图。
- 跟踪记录只追加，不覆盖历史；跨方法不写“目标价 A → B”，只写“方法 X 为 A；方法 Y 为 B，不可比”。
- 同一数据截止日内反向修正，必须写新增的非推断证据和 `stability_note`；只凭“人工判断偏高/偏低”或现价距离调整，标 `needs_review`。


判词只写判断，直接表达增长逻辑和估值结论，不写“仅供参考”“不能作为当前可执行目标价”等防御或免责声明。风险与限制只以事实写入“需人工复核”（如“分部乘数未记录依据”）。交付前调用 westock_query 获取最新行情；先去除 ticker 中文后缀、括号和空白并转换市场格式（02513.HK（港股）→hk02513）。market.price/currency/price_date/source/fetched_at 分别记录真实现价、币种、行情日期、来源和 ISO 获取时间，可用 quote_at 记录行情时间；失败时 price=null，记录获取时间和 fetch_error，显示“未获取”，不得沿用缓存价冒充实时价。verdict.valuation_id 引用原 valuations 中的模型价；结论卡同时展示模型价、现价、获取时间及空间=(模型价/现价-1)×100%；行情缺失或币种不一致则空间“未获取”。
