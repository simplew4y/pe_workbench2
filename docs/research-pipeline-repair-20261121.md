# 研究问答链路修复（2026-11-21）

本轮针对原评测中14道部分完成问题，检查最终答文、工具原始结果、审校记录和交付状态。修复集中在共享主链路，不按公司名、题号或期望答案分支。

## 问题与实现

| 链路 | 原问题 | 实现 |
| --- | --- | --- |
| 任务范围与路由 | 方法问题、虚构题设与现实取证混在一起；部分解释问法漏审 | `research-contract.mjs` 提取任务范围，`research-task.mjs` 统一识别；否定“虚构”的指令不激活题设规则 |
| 工具范围 | 只要求聊天回答却自行写报告，陷入保存修复 | `researchAnswerContext` 从当轮模型工具声明中移除报告写入、编辑和保存；明确文件操作保留，取证/计算/框架工具保留 |
| 外部取证 | `web_fetch` 拒绝官方PDF；简繁和字间空白影响检索 | 下载后在本地解析PDF，按查询选页；原文不改写，返回URL、物理页码、SHA-256、时间及截断信息 |
| 证据传递 | 大工具结果挤掉较早原文，旧草稿污染审校，恢复答复丢历史来源 | 按预算保留真实证据；审校去掉旧助手正文；只复用成功原文读取，旧答复不能代替来源 |
| 计算校验 | 审校心算与程序结果冲突；测试参数错绑原始基准 | 审校提供程序重新执行结果；计算回执 `activeInputs` 区分当前与基准输入 |
| 会计推理 | 缺成本算存货周转、税务扣除等同现金节税、减值推断已付款、擅加单位 | 狭窄的题设会计检查同时接入审校及交付，不能由宽松的语义回执豁免 |
| 状态交付 | 未来调查项被当漏答，失败尝试一律拖累交付，压缩后丢核验状态 | 以当前正文哈希绑定审校回执；仅明确无关或有真实替代证据的失败可解除；压缩后的合格答文携带新回执 |
| 修订恢复 | 输出修改说明、局部残片；前轮已读取数据又说没有 | 要求完整回答原问题，恢复上下文保留历史成功原文和原题范围 |

## 保留的边界

- 搜索摘要和失败工具不作为原始披露；历史助手答文不充当事实证据。
- 真实数值冲突、关键事实未取得、无效/过期审校回执仍不能作为完成依据。
- PDF抓取沿用现有网络安全检查，限制下载大小、解析时间和页数。新增能力只覆盖文本PDF；扫描文档返回需要OCR，不虚构内容。
- 会计检查是少量可识别错误的约束，不是完整会计推理引擎。自然语言推断仍需语义审校与最终答文复核。
- 交付状态与回答质量分别验收，不能靠提高 completed 数量宣称内容正确。

## 最终审校与证据修订

原文读取工具已经按页/查询限制返回长度，审校和恢复不能再任意删除中段；两者使用相同的原文节选上限。同一URL的不同页段读取独立保留，不能让最后一次查询覆盖之前的实际原文。

支持推理的模型使用最多24k预算的推理审校；只在输出长度截断时再尝试一次关闭推理的核验。调用失败与余额错误不走这条重试。成本累加独立于SDK用于上下文压缩的当前token大小。

主审校通过却漏填未知事项分类时，额外执行一次只判断任务范围的分类。必须覆盖所有真实项ID，伪造/重复/遗漏ID无效；用户本轮正面要求的事实缺失不被豁免。

任务合同区分财务期间和信息可得日。对于截至某日公开可核信息的任务，不要求使用该日期以后首次公布的回溯披露；引用某年度年报本身并不自动限制其次年正常发布日期。

PDF依赖复现：`python3 -m pip install -r requirements-pdf.txt`。锁定的PyMuPDF版本已通过真实PDF解析回归；可用`PYTHON_BIN`指定Python环境。


## 完整复测发现与补修

第五轮以8个新项目跑23道原题，含14道目标题和9道必要前序题。目标题12道completed、2道partial；全23题20道completed、3道partial。源文件哈希在结束后、补修前封存。完成状态不代表内容正确。

进一步发现事实记忆把“推翻条件”的阈值当历史已核事实，触发无意义改稿；新增`research-condition.mjs`，仅对研究方法题中明确的条件句区分其身份，已披露/已发生等事实断言仍核验。相关正反例使用不同数值，不按公司、题号或预期答案放行。

会计补修继续区分期末应收余额与年度收入流量，禁止直接据其比值宣称当年收入未回款比例；期后收款不能单独证明真实交易。语义审校同时明确平均应收口径、现金缴税与递延税项的区别。

第六轮计划使用2个新项目补验6道原题；收尾时已完成4道目标题，结束了1道未完成的前序题，另1道未启动。未完成结果不计通过或失败，其余题保留第五轮已完成记录。它是针对上述共享补修的复验，不是再次全量14题的同版本测试。逐题报告会注明所采用版本，不挑选旧轮次最好答案。

验收还发现若干过强因果判断、指标口径混用和冗长答复，独立审校也可能漏判或误判。不得把自动测试通过、completed状态或数量性取证，表述成已达到全面可靠的投研判断质量。回复耗时仍需改善。

最终逐题最新记录：13道completed、1道partial。仍未解决的是阳光电源框架题的取证/数值绑定与改稿稳定性；完整同版本第五轮为12道completed、2道partial。第六轮补验消除了条件命题的事实记忆误判，并改正应收真实性题的核心错误。9组回归检查通过。当前修复不代表全部推理、出处和篇幅要求均达标。
