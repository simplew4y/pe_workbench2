## 3. 真实数据与模型问答验收（尚未执行）

### 3.1 必需输入

1. 一组获准用于测试的真实 Excel 模型和 PDF 报告，至少包含两个主体、多个期间、实际与预测、不同量级/币种、重复数值及公式。
2. 人工核对的20个已披露事实作为 gold。每项记录主体、指标、期间、口径、实际/预测/假设、情景、原值、原单位、币种、来源文件 SHA/版本、页码或单元格、必要脚注，以及是否允许精确换算。
3. 独立测试项目与数据库副本、固定模型/路由/配置、允许的模型调用范围和预算。测试不得连接生产写入路径。
4. 另准备30个应当拒答或明确说明不确定的案例及预期行为。

未具备输入前，保持“未执行”，不要把生成 fixture 的单测冒充真实用户验收，也不要未经允许上传真实业务材料到额外服务。

### 3.2 360题矩阵

使用相同20事实，每项准备三种问法：直接问数值、同义/上下文追问、带明确换算或对比需求的问法。每种问法分别在建框架后的同一会话、无历史摘要的新会话执行，各重复三轮：

`20事实 × 3问法 × 2会话条件 × 3轮 = 360题`

执行顺序：

1. 走正常上传和投资框架流程，不预先手写事实库；保存工具调用记录与事实覆盖清单。
2. 对照 gold 检查首次实际看见的20项数据是否持久化，分清“未披露”“工具未返回”“返回但未登记”“登记后检索失败”。不能默认整个文件已被全部读入。
3. 保存“首次建框架完成”的数据库与项目快照。每轮、每种会话条件从这一相同快照的独立副本开始；同会话条件保留首次建框架会话，新会话条件禁用旧聊天摘要。提前固定是否允许题间累计新事实，并记录每题前的数据库版本，避免前轮回查结果污染后轮评分。
4. 三轮使用固定题集并记录顺序，不能用上一轮答案临时修订 gold。失败后修复代码应产生新报告，重跑完整矩阵。
5. 每次保留原始回答、工具调用、命中的 fact_id/version、来源版本、是否回查原文件、最终判分和错误分类。

通过标准：

- 整体正确率至少95%，即360题至少342题正确。
- 每轮120题的正确率不少于90%，即每轮至少108题正确。
- 错主体、错期间、实际/预测混淆、币种/量级错误、过期值冒充当前值、无依据精确数字、假引用等危险错误为0。
- 数字、单位和含义同时正确才计正确。换算与舍入按预先记录规则判定；不能仅比较裸数字。
- 已披露且在支持范围内的事实无故拒答，计为不正确；诚实拒答不能掩盖普通召回缺失。

### 3.3 30个拒答/不确定性案例

建议每类5例：来源未披露；实体/期间/口径歧义；来源冲突；旧版本/已过期；PDF脚注/扫描/截断无法验证；工具或存储故障。扫描等案例允许明确请求可核资料，不应凭空回答。

通过标准：30/30正确表达限制；无伪造来源或数字；工具故障不得称“文件未披露”；能回查时按允许方式回查，依然不确定时明确保留待核。

## 4. 变更、隔离和恢复的后续验收

以下均需在隔离项目中进行，不对生产数据做故障注入：

- **真实源更新**：同主体同期间更新源文件版本，旧事实/派生/框架失效；新版本来源可追踪，旧历史可查，不把旧数字作为当前结论。
- **定向更正**：更正一个 fact_id/version，不改另一个同值主体；框架受影响版本被标记，原模型/报告不被静默写回。
- **复杂格式**：Excel 百分比数值编码、公式缓存与实际重算、合并表头；PDF跨页表头、脚注和扫描。未支持场景应保持待核，不能通过提高质量标签绕过。
- **HTTP完整权限链路**：两个测试项目/身份交叉尝试引用源材料、证据、事实、框架和旧台账批次。应始终拒绝未授权读取/写入，而不是只依赖内存服务的项目限定。
- **负载与并发**：多会话同时读取/导入/提交/更新源版本，检查重复、锁等待、事务回滚、期望版本竞争和响应时间。已通过的两进程竞争不是高负载验收。
- **备份与灾难恢复**：在副本上恢复完整数据库与材料/导出目录，校验来源 SHA、事实版本与发布视图一致。索引重建不能恢复丢失的事实真值。
- **文件耐久性**：如果上线要求断电保证，需补充 fsync/目录刷盘策略及相应存储环境故障测试；当前只验证进程退出。

## 5. 性能与成本（尚未执行）

对同一真实题集、相同模型配置和源文件，用未启用本功能的基线与本分支各测至少三轮。记录冷启动/热查询、新会话、源更新后查询：

- p50/p95 端到端延迟及工具/检索/导出分段时间。
- 每题输入/输出 tokens、模型调用数、原文件重读次数、失败重试数。
- 数据库/证据存储增量，以及20/100/1000事实规模下查询成本。

使用原方案的建议预算：在满足准确性与危险错误标准的前提下，延迟与 token 增幅以不超过30%作为初始目标。测试前固定口径；不把尚未测量的指标填写为0或通过。即使更快，只要危险错误不为0就不能验收。
