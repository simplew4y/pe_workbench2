# 工具错误、报告审校与无效往返修复

日期：2026-11-22。基于 3191b07 的本地工作区修改。未提交、推送或部署，未新增付费模型请求。腾讯2原追问仍在运行，未取消、未重启 8081，也未回写原会话或报告。

## 本轮改动

1. **普通工具结果与展示契约分开。** 没有展示契约的普通文本/structuredContent 不生成坏卡片错误；明确声明但损坏的展示契约仍报错。历史成功 read 中精确的旧“无结构化展示”错误不再展示，其他错误保留。实时事件与刷新快照均测试。
2. **报告统一保存入口。** 注册受控 write，exports/ 下 Markdown 报告自动进入 review_research。同一次调用完成审校和保存，不先返回一次“请换工具”的失败。审核未通过不会写入。直接调用 review_research 保存时，SDK 的嵌套 write 使用一次性的精确正文授权，避免重复审校/递归；路径、只读边界、文件基线和完整回读验证保留。
3. **状态结构提前准备、保存时立即校验。** validate_state(action=template) 返回现有空白模板及与校验器共享的枚举。write analysis-state.json 在同一回执返回所有结构错误和警告，明确“已保存”与“结构通过”不同。技能不再要求同内容重复校验。没有自动填造来源、阈值、预测或 armed 状态。
4. **报告复用已读事实。** 同一身份、单位、期间、版本与数值通过确定性比较的工作簿事实可生成自动绑定回执；显式来源中的逐字原文也可绑定。只凭同值、已成功算过算术、或者 sources 列表存在，都不能放行。新来源、错币种、错期间、错指标、旧版本与同句重复数字的正反例已覆盖。
5. **元数据与财务主张分开。** 证券代码、带标签的截止日期和投资期限不再作为未登记的财务金额；同一行中的利润、回报率等实质数字仍检查。不将整行或整段简单豁免。
6. **审校异常不冒充财务错误。** numeric_units=fail 但理由明确“数值一致、未发现冲突”的条目隔离到 rejectedIssues，保留协议异常而不升级为通过。审校不可用时，数字绑定待核单独保留，不能将几十条待核内容都称为已确认错误，再要求模型删掉正文数字。
7. **减少重复调用与反馈体积。** 同轮同稿、同证据、同相关文件、同审校配置的报告重复提交复用原结果；新证据、状态变化、新一轮问题或审校配置变化会失效。保留完整 details，给模型的反馈去掉重复覆盖列表，以完整行号列表标注待核位置。所有实际错误仍可见。
8. **比例单位显式化。** calc 输出百分数必须明确 percentage_points，或通过 decimal→% 换算；不靠数值大小或算式猜单位。不再给比例/倍数挂 HKD 等币种标签。小于 1 的真实百分数仍可声明并使用。旧记录不会被静默重写。
9. **网络错误可诊断。** 保留安全的底层 causeCode，例如 ECONNRESET，不输出底层可能包含凭据的消息。未据此声称外站连接问题已恢复。

## 性能边界

本轮没有关闭默认推理，没有新增总时长取消，没有跑真实付费问答。

报告自动绑定只做直接已读事实的快速检查；先按候选数值筛选，再做完整身份比较，候选过多则保留待核。不会把所有 trace 图和历史文本反复送入每个数字的匹配循环。计算、情景和歧义行仍由完整证据审查处理。

能验证的是减少无效工具往返、重复审校与重复反馈，不能据此承诺真实回答从多少分钟降到多少分钟。模型生成、有效取证和实质修订仍需要时间。
