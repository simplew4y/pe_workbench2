## 修复内容与原因

### 1. 页面、报告与 JSON 的版本不一致

原问题不只是“文件未保存”。M02 的报告第三次审校曾落盘，后续三次修订被拒；交付层却用旧文件 saved:true 反驳“新版未发布”。同一个 F3 在页面、JSON、旧报告分别代表毛利率、DDR4 价格和 DDR5 价格，不能混合展示或启用跟踪。

现在按版本交付：

- 报告、状态、delivery-manifest.json 共同携带版本和全文哈希。页面持久化正文与报告文件逐字相同，不再在报告保存后单独追加一份不同的交付尾注。
- 只有本轮实际写入、回读哈希一致的文件才允许替换；外部改动、越界路径、符号链接和拒绝写入均阻断覆盖。发布中途失败回滚，发布前检查文件基线，清单最后写入。
- 报告审校同时看到同目录状态的精确快照；宿主记录报告与状态的审校哈希，状态后来改变会使绑定失效。
- 没有可靠同版审校证据时，研究状态保持 partial，JSON 标为 pending_alignment；清空当前激活的观点/假设/敏感性/估值/失效条件关联，移除旧展示卡片，暂停监控。保留旧文件和完整候选 JSON、最新报告候选稿及哈希，以供接力复核。
- 跟踪工具与定时跟踪服务在读取时核对清单及两个文件哈希；待核、清单缺失、内容被改动或发布进行中均不能启用候选条件。

**这是一条诚实的降级交付路径，不是自动重建完整投资框架。** 对齐且经过审校的状态会保留其观点和监控条目；无法对齐的状态不会靠猜测正文阈值而强行激活。

主要代码：lib/report-publication.mjs、lib/delivery-bundle.mjs、lib/research-review.mjs、lib/artifact-delivery.mjs、server/agent/post-answer.mjs、lib/tracking-tool.mjs、server/tracking/service.mjs。

### 2. 数字校验误伤

M02 的工作簿把 Net income 同时写入 label 和 product。补充语义时，原净利指标被错误清空并当成业务分部；另一条派生“现市值对应净利倍数”又因包含“净利”二字，被当成净利金额来源。因此 745,399 百万元被错误要求改成“倍”。

修复后保留财务行指标身份，区分原始金额与派生比值，识别明确的市值/净利市盈率口径；不再拿金额单位反驳明确的漏损等比例。没有足够分子分母或身份信息时仍提示缺证，不直接认定比例正确。

题设增长 15% 改写为“游戏 +15%”可按同主体、同方向、同值识别。更换主体、数值或正负号仍阻断。无单位虚构情景的金额规则只约束题设推演，不能误伤同句有年份、披露标记与出处的历史金额；同段随后编造的情景单位仍会被拦截。

主要代码：lib/financial-evidence.mjs、lib/financial-source-identity.mjs、lib/research-reasoning.mjs。

### 3. 正文裁剪与残留

原先按局部数字或句子替换后，还会留下“这是……”“因此……”的解释、被删除 T/V/F 条目的后续引用，以及只剩标题的章节。

现在在语义审校替换与最终交付两层处理：完整语句边界、紧随其后的依赖解释、跨段编号及范围引用、表格条目之间的传递依赖。缺失定义不能继续支持后续结论；受损表格不能继续支持未独立取证的敏感性排序。空章节汇总为明确的未交付范围，保留独立成立的事实。

还新增了交付占位句检查：模型复述宿主裁剪模板不能因此被标成 completed。缺口列表也不再原样复述刚刚拒绝的断言。

主要代码：lib/research-document-closure.mjs、lib/research-text-boundaries.mjs、lib/research-delivery.mjs、lib/answer-lint.mjs、server/agent/answer-delivery.mjs。

修复中发现并处理了以下问题：

1. 待核 JSON 不能删除 schema 必需的 tracking 对象，改为保留空对象。
2. 依赖清理曾误删独立的下一句，收窄为显式指代/因果延续，并保留原回归中的独立事实断言。
3. 缺口尾注可能重现被拒摘录，已去除原样重复。
4. 格式回归原来把宿主裁剪占位句当成“仅格式问题”；改用普通研究句测试格式，占位句另由交付回归验证为不能直接完成。
5. 回放最初没有恢复嵌套审校写文件的成功回执，已按原始 research_write_verified 哈希恢复，并在临时副本中发布，所有原始记录保持只读。

## 尚未解决及接力边界

- **研究内容仍未齐全。** M02、R6 还存在真实缺证、来源身份不完整、部分派生指标关系未核验、负向模型路径断言缺少成功工具证据等问题。当前只交付有据部分，不声称已形成完整可跟踪框架。
- **降级 JSON 暂不包含活动观点图。** 候选资料并未丢失，但需要补充证据和同版审校后才能重新发布。不能把空监控计划当成投资研究目标已达成。
- **普通部分完成题仍有原因。** T01-R4 录制稿已缺少应下调命题的实质答复；T03-R1 仍有派生占比计算未成功；T04-R1 的公开披露边界和语义断言仍待核验；T07-R4 的终值分母为零，数学边界解释可以成立，但原记录的失败工具处置未补齐。本轮没有伪造新的计算或替模型作新的审校。
- **语义不一致不是全确定性可判定。** 本轮通过精确版本绑定加审校快照约束，并对无法证明一致的状态暂停使用；不能保证未来审校模型永不误判。
- **裁剪仍有保守性。** 正文可能较短，失去表格依据的无独立出处论述会撤回。未构造新的推理补足原稿，也没有把全篇改写成投研专家口吻。跨句隐含因果及语义重复仍可能需要进一步改进。
- **后续状态修改需重新绑定。** 任何写入改变已发布状态文件的字节，都会使原清单失效并暂停跟踪，需要重新发布同版报告/状态；本轮没有为所有独立编辑入口增加自动再审校。
- **本轮未验真实模型效果或实际浏览器渲染。** 页面验证指后端持久化交付和页面快照投影测试；不能据此宣称新一轮 50+1 题真实验收通过。
